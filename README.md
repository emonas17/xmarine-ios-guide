# Xmarine iOS guide

[Download the illustrated HTML guide](./Xmarine-iOS-Guide.html?raw=true) and open it in Safari, Chrome, or another browser. The screenshots are included in the file and available offline.

The guide covers NMEA3WiFi gateway setup, connecting Xmarine on iPhone or iPad, reading the cockpit, and autopilot control with compatible SeaTalk1 equipment.
